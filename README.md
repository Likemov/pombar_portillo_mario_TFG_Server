PROYECTO GESTOR DE VIAJES Y TRANSPORTE PÚBLICO - SERVIDOR

Este repositorio contiene la aplicación servidor del Proyecto de Fin de Grado "Gestor de Viajes y Transporte Público", para el Ciclo Formativo de Grado Superior Desarrollo de Aplicaciones Multiplataforma (modalidad Virtual).

REQUISITOS:
- Docker Desktop: https://www.docker.com/products/docker-desktop/

MÉTODO DE EJECUCIÓN:
- Descarga el repositorio (https://github.com/Likemov/pombar_portillo_mario_TFG_Server/archive/refs/heads/main.zip)
- Descomprime la descarga
- Ejecuta server.bat

Si se desean añadir viajes a la base de datos, se necesitará manipularla mediante un SGBD.

RECOMENDACIONES DE SGBD:
- MySQL Workbench: https://www.mysql.com/products/workbench/
- DBeaver: https://dbeaver.io/
